# Airport Express

Airport Express marketing website for a San Francisco transportation company.

## Local development

```bash
npm install
npm run dev
```

Open the local URL printed by Next.js. Use `npm run lint`, `npm run typecheck`, and `npm run build` for quality checks.

## Project notes

- Active work belongs on `airport-express-development`; `main` is reserved for stable changes.
- The content audit and business questions are in [`docs/content-audit.md`](docs/content-audit.md) and [`docs/client-verification.md`](docs/client-verification.md).
- Booking links open the existing Airport Express reservation page. The live form has not been submitted or verified end to end.
- The production reservation handoff, exact service coverage, pickup procedures, and policy details must be confirmed before launch.
